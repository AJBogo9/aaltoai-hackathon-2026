What the deck shows

A folder carries a level in .confidentiality.json. A provider carries a clearance. A provider cleared below a folder's level gets no access to it at all, not even a file listing.

It is a guardrail, not a sandbox. It stops the tool calls it mediates, and it says out loud which check refused.
