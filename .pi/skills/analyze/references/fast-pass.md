# Fast fault pass (low accuracy)

Speed over accuracy. One script, one run, done in seconds. Do not reason file
by file, do not iterate, do not verify.

## Do exactly this

0. Take the workspace path from your system prompt (`## Workspace`). Every
   path below is relative to it: read from the first of
   `<workspace>/sensordata`, `<workspace>/data` or the workspace root that
   holds `*.csv`, and write to `<workspace>/reports`. Do not resolve paths
   against this file's location or the working directory — pi keeps cwd
   outside the workspace and blocks writes there. No workspace set: stop and
   tell the user to restart pi with `scripts/launch.sh <folder>`.
1. Write **one** Python 3 script (stdlib only: `csv`, `statistics`, `math` —
   no venv, no installs, no pandas) that loops over every CSV in that input
   folder and, per file, mechanically emits
   `<workspace>/reports/<filename>.json`.
2. Run it once.
3. Write `<workspace>/reports/summary.md` — one line per file, generated by
   the same script.
4. Stop. Do not review the output or improve it.

## What the script does per file

- **schema**: one entry per column, filled in by rule, not by thinking.
  `sample`/`timestamp` → `role: index`. Everything else → `role: observed`,
  `type` guessed from the column's value range or just `"flow"`.
  `confidence: 0.3`, `evidence: "range-based guess"`.
- **findings**: for each column, flag a block only if something is trivially
  obvious in a single pass — missing/empty values, a run of identical values,
  a value far outside the column's own range, or the largest jump in the
  block medians. Cap it at a handful of findings per file; empty `findings`
  is fine.
  - missing / frozen / duplicate / impossible → `layer: "record"`
  - biggest median jump, one column only → `layer: "measurement"`
  - biggest median jump, several columns at once → `layer: "system"`
  - `window`: the block bounds. `onset_estimate`: the block start.
  - `confidence: 0.3`, `evidence`: the number that triggered it.

Thresholds are arbitrary — pick one, don't tune it. Wrong labels are
acceptable.

## Output

`reports/<filename>.json`:
```json
{
  "schema": [
    {"column": "", "type": "", "role": "observed|actuated|index",
     "confidence": 0.0, "evidence": ""}
  ],
  "findings": [
    {"column": "", "window": [0, 0], "layer": "record|measurement|system",
     "fault_type": "", "onset_estimate": 0, "confidence": 0.0, "evidence": ""}
  ]
}
```
`reports/summary.md`: one plain line per file.

Never read `truth/` or `labels/`.
