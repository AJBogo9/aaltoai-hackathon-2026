# MachineBlock

Verbatim terminal output on an inset paper ground: the product's own words, quoted rather than described.

This is the borrowed strength of the whole system. A refusal printed by the broker is more
persuasive than any sentence about the broker, so the deck quotes it at readable size and the
prose around it only points.

**The consumer provides** the pasted output. Nothing here is retyped, tidied, shortened or
re-cased. If the line is too long for the slide, shorten the command that produced it and
run it again.

Rules:

- `paper-100` ground, `machine` type style, `radius-flat`. On a slide the block sits inside
  the `space-5` gutter.
- Prompts and commands in `ink-600`, output in `ink-900`.
- A refusal glyph and its reason in `signal-refuse`, an allow in `signal-allow`. Those are
  aliases of the level colours, so a refusal is never a new red.
- Never a screenshot. A screenshot of a terminal cannot be read from the back of a room and
  cannot be diffed against the real output.
