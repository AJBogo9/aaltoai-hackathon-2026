# Building the deck

The deck is seven 16:9 slides, generated by
[`scripts/build_deck.py`](../../scripts/build_deck.py) and presented from the PDF export.
Edit the script, rebuild, re-export. A hand edit in LibreOffice is dropped by the next rebuild.

The opening is a before and after on one drawing: the stakes, the data path today, the same
path with the broker, then the rule. That map is the deck's one chart, and it obeys the chart
rule: hairlines for the borders, one thick rule per data path in the colour of the data's
level, the product's own `●` glyph at each end, no arrows and no icons.

## Geometry

A slide is 13.333in by 7.5in. Work in the 1280x720 px reference the tokens use and convert
once: **points = px x 0.75**, inches = px / 96.

| Part | Px at 1280 | Points |
| --- | --- | --- |
| Gutter, left and right (`space-5`) | 64 | 48 |
| Band height (text 17px plus `space-2` twice) | 45 | 33.75 |
| Headline size (`headline`) | 58 | 43.5 |
| Sub size (`sub`) | 24 | 18 |
| Machine block size (`machine`) | 18 | 13.5 |
| Column gap (`space-6`) | 88 | 66 |
| Content width (1280 less two gutters) | 1152 | 864 |

The bands run full bleed: they start at x=0 and span the full width, through the gutter.
Everything else stays inside it.

**The gutter is 5 percent of the slide width, and that is the point.** A projected page
reads as crowded long before a screen does, so the deck buys its air from the margins
rather than from smaller type: the headline stays 58px. If a slide still feels tight, the
slide has too much on it, and the fix is a second slide.

## Order of a slide

1. Top band: the level word alone, `band-ink` on the level fill. The cleared providers
   are named on the routing slide, where they carry an argument, not on every page.
2. Eyebrow in `ink-400`, uppercase.
3. Headline, one claim, sentence case, `ink-900`.
4. Sub line in `ink-600`, at most two lines.
5. The body: either two fields (label over a hairline, mono value under it) or one machine
   block quoted from the terminal.
6. Kick line above a `rule-200` hairline, stating the consequence.
7. Bottom band, repeating the level.

## Rules that are easy to break

- **The band tracks the page.** `WHAT WE BUILT` is `public` because nothing confidential
  is on it.
  Recheck every band whenever a slide's content changes. See the marking rule in the README.
- **Never retype terminal output.** Paste it. The credibility of the whole deck rests on the
  audience believing the block is real.
- **Bash is not in the tool list.** When a slide lists what stopped an injection, the
  wording matches the product's own reason strings.
- **No fourth colour.** A chart, if one is ever needed, uses ink and one level colour.
- **Test the export, not the source.** LibreOffice substitutes a missing face silently, so
  export the PDF and look at it before believing the deck.
