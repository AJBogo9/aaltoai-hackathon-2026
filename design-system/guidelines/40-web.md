# The web surfaces

Two of them: the GitHub Pages site under `site/`, which is where the deck link points,
and the component previews in this folder's `components/*/preview.html`.

## Tokens come from a file, never from a keyboard

`design-system/tokens.css` is generated by `scripts/brand.py` and holds every colour in
both themes, the three families, the spacing scale, the radii and the one shadow. A
preview links it:

```html
<link rel="stylesheet" href="../../tokens.css">
```

The site is deployed as a folder of static files and is read on phones, so it inlines the
same values instead, inside the `/* brand:tokens */` region that the generator fills. Both
routes end at `tokens.json`. A hex value typed into a stylesheet is a bug, and
`python3 scripts/brand.py --check` fails on it.

## Load the fonts, or the page is not in this system

PT Serif, PT Sans and PT Mono are installed on the presenting machine, which is exactly
why a missing `<link>` is invisible to us and obvious to a judge. Every web surface loads
them:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=PT+Serif:wght@400;700&family=PT+Sans:wght@400;700&family=PT+Mono&display=swap">
```

Without it the serif falls back to Georgia and the argument that quoted machine output
looks different from our prose quietly stops being true.

## What a web page carries that a slide does not

- **A band, top and bottom**, the same component at web scale. The page is public, so it
  says `PUBLIC` and lists the six cleared providers, read from the policy.
- **A favicon**, `site/favicon.svg`, which is the band and nothing else. No lock, no
  shield, no key.
- **A social card**, `site/social-card.png` at 1200x630, so a link pasted into a judging
  chat arrives marked:
  ```html
  <meta property="og:image" content="https://<pages-host>/social-card.png">
  ```
  It is the banner on a taller canvas. Regenerate it with the covers, never by hand.
- **Rounded corners, but barely.** `radius-chip` for a level chip, `radius-panel` for a
  code fence, matching GitHub's own 6px. The deck stays square.

## Rules that survive a phone

- One column under 700px. The band stacks, its letterspacing drops, and the provider list
  wraps rather than scrolls.
- The headline drops from 58px to 34px. Nothing else changes size, because nothing else
  was sized by eye.
- Tap targets are the links themselves. There is no hamburger, because there is one page.
